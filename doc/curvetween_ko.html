CurveTween 문서

기능 목록

▶ Fade（페이드)

오브젝트의 투명도(Alpha)를 애니메이션합니다.

• 지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 사용 예시
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（이동)

Transform의 위치를 애니메이션합니다.

• 사용 예시
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（확대/축소)

Transform의 스케일을 애니메이션합니다.

• 사용 예시
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（회전)

Transform의 회전을 애니메이션합니다.

• 사용 예시
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（컬러)

Color 값을 애니메이션합니다.

• 지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 사용 예시
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

타이핑 효과의 텍스트 애니메이션을 제공합니다.

• 사용 예시
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ RichText (TextMeshPro)

리치 텍스트를 지원하며, 타이핑 스타일 애니메이션, 회전 애니메이션, 글꼴 크기 확대·축소 애니메이션을 제공합니다.(GC 부하가 높기 때문에 성능에 주의해야 합니다.)

• 사용 예시
  • target.DoRichTextReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Unity Light 컴포넌트의 다양한 속성을 애니메이션합니다.

• 지원 속성
  • - color
  • - intensity
  • - range
• 사용 예시
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ FillAmount

Image 컴포넌트의 fillAmount 값을 애니메이션하는 기능입니다. 게이지, 쿨다운, 원형 로딩 등 UI 표현에 사용할 수 있습니다.

• 대상
  • - Image (Filled 타입)
• 사용 예시
  • target.DoFillAmount(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ IntInterpolate / FloatInterpolate

Text / TextMeshPro의 숫자 값을 보간하여 애니메이션으로 표시하는 기능입니다. 카운트업, 데미지 숫자, 점수 연출 등에 적합합니다.

• 대상
  • - Text / TextMeshPro
• 사용 예시
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TMPMeshExplodeInAnimation

TextMeshPro의 정점 데이터를 직접 조작하여 각 문자를 개별적으로 폭발시키는 애니메이션입니다. 속도, 방향, 확산 정도, 랜덤성 등을 세밀하게 제어할 수 있어 화려한 연출에 적합합니다.

• 대상
  • - TextMeshPro
• 사용 예시
  • path.DoMeshExplodeIn()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 사용 예시
  • path.DoMeshExplodeIn()
  • .SetExplosionPower(power)
  • .SetUseFadeOut(true).SetFadeDelay(delay)
  • .SetUseRotate(true).SetValue(min, max)
  • .SetUseFloatiness(true).SetValue(min, max)
  • .Play();

▶ TMPMeshRevealAnimation

TextMeshPro의 정점을 직접 조작하여 다음과 같은 복합적인 문자 연출을 구현하는 애니메이션입니다: Fade(투명도), 문자 스케일, 회전, 이동, 웨이브 변형, 바운스 변형. 타자기 효과부터 역동적인 문자 애니메이션까지 폭넓게 지원합니다.

• 대상
  • - TextMeshPro
• 사용 예시
  • path.DoMeshReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 사용 예시
  • path.DoMeshReveal()
  • .SetFadeTween(true).SetValue(alpha)
  • .SetScaleTween(true).SetValue(scale)
  • .SetPosTween(true).SetValue(pos)
  • .SetWave(WaveType).SetFactor(float)
  • .SetRotTween(true).SetValue(rot)
  • .Play();

▶ PathCurveAnimation

여러 포인트로 구성된 커브(경로)를 따라 오브젝트를 이동시키는 애니메이션 기능입니다.

• 사용 예시
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

API 참고 문서

▶ DoCanvasFade

CanvasGroup의 alpha 값을 애니메이션하기 위한 유틸리티 메서드입니다.

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• 파라미터
  • - GameObject target：
  • 페이드 대상이 되는 UnityEngine.GameObject입니다. CanvasGroup이 부착되어 있지 않다면 자동으로 추가하여 사용합니다.
  •  
  • - MonoBehaviour target：
  • 페이드 대상이 되는 컴포넌트입니다. CanvasGroup이 없을 경우 자동으로 추가하여 사용합니다.
  •  
  • - CanvasGroup target：
  • 페이드 대상이 되는 CanvasGroup 컴포넌트입니다.
  •  
  • - float forwardValue：
  • 애니메이션 시 forward 방향의 목표 알파 값(0〜1)입니다.
  • 정방향 재생: 현재 alpha → forwardValue.
  • 역방향 재생: forwardValue → 현재 alpha.
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts 값을 설정할지 여부입니다.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초)입니다.
  •  
  • - AnimationCurve curve：
  • 애니메이션 진행에 사용되는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간이 되므로 duration은 무시됩니다.

  • 역방향 재생: intensity → 현재 값.

IRevealPlayer DoMeshReveal(this TMP_Text target, bool reveal = true, string text = null, bool fadetween = false, float alpha = 1, bool postween = false, Vector3 distance = default, bool scaletween = false, float scale = 1, bool rotatetween = false, Vector3 rotate = default, WaveType wavetype = WaveType.None, float frequency = 0, float duration = 1);

IRevealPlayer DoMeshReveal(this TMP_Text target, AnimationCurve curve, bool reveal = true, string text = null, bool fadetween = false, float alpha = 1, bool postween = false, Vector3 distance = default, bool scaletween = false, float scale = 1, bool rotatetween = false, Vector3 rotate = default, WaveType wavetype = WaveType.None, float frequency = 0);

• 매개변수
  • - TMP_Text target：
  • 애니메이션 대상이 되는 TMPPro.TMP_Text 컴포넌트입니다.
  •  
  • - bool reveal：
  • 타자기 방식의 문자 등장 애니메이션(Reveal)을 사용할지 여부입니다.
  •  
  • - string text：
  • 기존 텍스트에 추가할 문자열입니다.
  • 타자기 애니메이션으로 표시할 문자열입니다.
  •  
  • - bool fadetween：
  • 페이드 애니메이션을 사용할지 여부입니다.
  •  
  • - float alpha：
  • 정방향 재생: alpha → 1.
  • 역방향 재생: 1 → alpha.
  •  
  • - bool postween：
  • 이동 애니메이션을 사용할지 여부입니다.
  •  
  • - Vector3 distance：
  • 정방향 재생: distance → Vector3.zero.
  • 역방향 재생: Vector3.zero → distance.
  •  
  • - bool scaletween：
  • 스케일 애니메이션을 사용할지 여부입니다.
  •  
  • - float scale：
  • 정방향 재생: scale → 1.
  • 역방향 재생: 1 → scale.
  •  
  • - bool rotatetween：
  • 회전 애니메이션을 사용할지 여부입니다.
  •  
  • - Vector3 rotate：
  • 정방향 재생: rotate → Vector3.zero.
  • 역방향 재생: Vector3.zero → rotate.
  •  
  • - WaveType wavetype：
  • None
  • Wavy
  • Bounce
  •  
  • - float frequency：
  • Wavy / Bounce 사용 시의 주파수 값입니다.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초)입니다.
  •  
  • - AnimationCurve curve：
  • 애니메이션 진행에 사용되는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간으로 사용되므로 duration은 무시됩니다.

▶ Path Settings

여러 포인트로 구성된 커브(경로)를 따라 오브젝트를 이동시키는 애니메이션 기능입니다.

IPathPlayer SetClosed(bool closed);

  • 경로의 시작점과 끝점을 연결할지 설정합니다.
• 파라미터
  • - bool closed：
  • true：닫힌 루프
  • false：열린 경로

IPathPlayer SetLookMode(PathLookMode lookmode);

  • 이동 중 오브젝트가 바라볼 방향을 설정합니다.
• 파라미터
  • - PathLookMode lookmode：
  • None：방향을 변경하지 않음
  • Forward：경로의 진행 방향(접선 방향)을 바라봄
  • Right：진행 방향 기준 +X 방향
  • Left：진행 방향 기준 –X 방향

IPathPlayer SetPoints(List vectors);

  • 경로를 구성하는 제어점 리스트를 설정합니다.

IPathPlayer SetTarget(Transform target);

  • 경로를 따라 이동할 대상 Transform을 설정합니다.

IPathPlayer SetUseLocalPosition(bool uselocal);

  • 로컬 좌표를 사용할지 설정합니다.
• 파라미터
  • - bool uselocal：
  • true：로컬 좌표 사용
  • false：월드 좌표 사용

IPathPlayer SnapTargetToFirstPoint();

  • 대상의 위치를 경로의 첫 번째 포인트로 이동시킵니다.

iTweenPlayer SetDelay(float delay);

  • 애니메이션 시작 전 지연 시간을 설정합니다.

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • 애니메이션을 재생합니다.
• 파라미터
  • - bool reversePlay：
  • reversePlay = true: 역방향 재생

void PlayOnce();

  • 한 번만 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void PlayReverseOnce();

  • 역방향으로 한 번 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void Stop();

  • 재생 중인 애니메이션을 중지합니다.

void ForceEnd(bool invokeCallback);

  • ForceEnd 메서드는 정상적인 종료 흐름을 무시하고 즉시 처리를 종료합니다.
• 파라미터
  • - bool invokeCallback：
  • true：강제 종료 후 완료 콜백을 실행함.
  • false：완료 콜백을 실행하지 않음.

void StopAndReset();

  • 애니메이션을 중지하고 초기 상태로 되돌립니다.

iTweenPlayer AddOnStartListener(UnityAction call);

  • 애니메이션 시작 시 호출됩니다.

iTweenPlayer AddOnYoYoListener(UnityAction call);

  • YoYo 애니메이션에서 0 → 1 도달 시 호출됩니다.

iTweenPlayer AddOnCompleteListener(UnityAction call);

  • 애니메이션 완료 시 호출됩니다. (루프 중에는 호출되지 않음)
