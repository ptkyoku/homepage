CurveTween 문서

기능 목록

▶ Fade（페이드)

오브젝트의 투명도(Alpha)를 애니메이션합니다.

・지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
・예시
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（이동)

Transform의 위치를 애니메이션합니다.

・예시
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（확대/축소)

Transform의 스케일을 애니메이션합니다.

・예시
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（회전)

Transform의 회전을 애니메이션합니다.

・예시
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（컬러)

Color 값을 애니메이션합니다.

・지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
・예시
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

타이핑 효과의 텍스트 애니메이션을 제공합니다.

・예시
  • target.DoTextTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TextPro (TextMeshPro)

리치 텍스트, 타이핑 애니메이션, 회전 애니메이션, 폰트 크기 스케일 애니메이션을 지원합니다.

・예시
  • target.DoTextProTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Unity Light 컴포넌트의 다양한 속성을 애니메이션합니다.

・지원 속성
  • - color
  • - intensity
  • - range
・예시
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ PathCurveAnimation

여러 포인트로 구성된 커브(경로)를 따라 오브젝트를 이동시키는 애니메이션 기능입니다.

・예시
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

API 참고 문서

▶ DoCanvasFade

CanvasGroup의 alpha 값을 애니메이션하기 위한 유틸리티 메서드입니다.

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this MonoBehaviour target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this MonoBehaviour target, float forwardValue, float duration = 1);

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, float duration = 1);

・파라미터
  • - MonoBehaviour target：
  • 페이드 대상이 되는 컴포넌트. CanvasGroup이 없을 경우 자동으로 추가하여 사용합니다.
  •  
  • - CanvasGroup target：
  • 페이드 대상이 되는 CanvasGroup 컴포넌트.
  •  
  • - float forwardValue：
  • 정방향 재생 시 도달할 alpha 값(0–1).
  • 정방향: 현재 alpha → forwardValue
  • 역방향: forwardValue → 현재 alpha
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts 값을 설정할지 여부.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초).
  •  
  • - AnimationCurve curve：
  • 사용자 정의 애니메이션 커브.
  • 커브의 시간축이 애니메이션 시간으로 사용되므로 duration은 무시됩니다.

  • 애니메이션에 걸리는 시간(초).
  •  
  • - AnimationCurve curve：
  • 사용자 정의 애니메이션 커브.
  • 커브의 시간축이 애니메이션 시간으로 사용되므로 duration은 무시됩니다.

▶ Path Settings

여러 포인트로 구성된 커브(경로)를 따라 오브젝트를 이동시키는 애니메이션 기능입니다.

SetClosed(bool closed);

  • 경로의 시작점과 끝점을 연결할지 설정합니다.
・파라미터
  • - bool closed：
  • true：닫힌 루프
  • false：열린 경로

SetLookMode(PathLookMode lookmode);

  • 이동 중 오브젝트가 바라볼 방향을 설정합니다.
・파라미터
  • - PathLookMode lookmode：
  • None：방향을 변경하지 않음
  • Forward：경로의 진행 방향(접선 방향)을 바라봄
  • Right：진행 방향 기준 +X 방향
  • Left：진행 방향 기준 –X 방향

SetPoints(List vectors);

  • 경로를 구성하는 제어점 리스트를 설정합니다.

SetTarget(Transform target);

  • 경로를 따라 이동할 대상 Transform을 설정합니다.

SetUseLocalPosition(bool uselocal);

  • 로컬 좌표를 사용할지 설정합니다.
・파라미터
  • - bool uselocal：
  • true：로컬 좌표 사용
  • false：월드 좌표 사용

SnapTargetToFirstPoint();

  • 대상의 위치를 경로의 첫 번째 포인트로 이동시킵니다.

▶ CurveTween Settings

SetDelay(float delay);

  • 애니메이션 시작 전 지연 시간을 설정합니다.

SetDuration(float duration);

  • 애니메이션 지속 시간을 설정합니다.

SetEase(EaseType easeType);

  • EaseType에 따른 0–1 정규화 커브를 설정합니다.

SetLoop(bool loop);

  • 애니메이션 반복 여부를 설정합니다.

SetLoopCount(int loopCount);

  • 반복 횟수를 설정합니다.

SetLoopDelay(bool loopDelay);

  • 반복 시 delay를 적용할지 설정합니다.

SetLoopType(LoopType loopType);

  • 반복 방식 설정
・파라미터
  • - LoopType loopType：
  • Resart：0 → 1 반복
  • YoYo：0 → 1 → 0 반복
  • Increment：기존 값에 누적

SetScaledTime(bool scaledtime);

  • Time.timeScale에 의존할지 설정합니다.

SetYoYoDelay(float yoYoDelay);

  • YoYo 모드에서 0 → 1 도달 후 역방향 재생 전 지연 시간.

SetValue(object value);

  • 애니메이션 시작 전에 target 또는 forwardValue를 초기화합니다.
  • 지원 타입: CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float 등

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • 애니메이션을 재생합니다.
・파라미터
  • - bool reversePlay：
  • reversePlay = true: 역방향 재생

void PlayOnce();

  • 한 번만 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void PlayReverseOnce();

  • 역방향으로 한 번 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void Stop();

  • 재생 중인 애니메이션을 중지합니다.

void StopAndReset();

  • 애니메이션을 중지하고 초기 상태로 되돌립니다.

▶ Event Callbacks

void AddOnStartListener(UnityAction call);

  • 애니메이션 시작 시 호출됩니다.

void AddOnYoYoListener(UnityAction call);

  • YoYo 애니메이션에서 0 → 1 도달 시 호출됩니다.

void AddOnCompleteListener(UnityAction call);

  • 애니메이션 완료 시 호출됩니다. (루프 중에는 호출되지 않음)
