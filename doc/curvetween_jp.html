CurveTween ドキュメント

機能一覧 (Features)

▶ Fade（フェード)

オブジェクトの透明度（Alpha）をアニメーションします。

・対象
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
・使用例
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移動)

Transform の位置をアニメーションします。

・使用例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（拡大縮小)

Transform のスケールをアニメーションします。

・使用例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（回転)

Transform の回転をアニメーションします。

・使用例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（カラー)

色（Color）をアニメーションします。

・対象
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
・使用例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

テキストのタイピング風アニメーションします。

・使用例
  • target.DoTextTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TextPro (TextMeshPro)

リッチテキストに対応し、タイピング風アニメーション、回転アニメーション、フォントサイズの拡大縮小アニメーションをサポートします。

・使用例
  • target.DoTextProTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Unity Light コンポーネントの各種プロパティをアニメーションします。

・対象
  • - color
  • - intensity
  • - range
・使用例
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ PathCurveAnimation

PathCurveAnimation は、複数のポイントで構成されたカーブ（パス）に沿って対象オブジェクトを移動させるアニメーション機能です。

・使用例
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

APIリファレンス

▶ DoCanvasFade

CanvasGroupの alpha をアニメーションさせるためのユーティリティメソッドです。

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this MonoBehaviour target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this MonoBehaviour target, float forwardValue, float duration = 1);

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, float duration = 1);

・パラメータ
  • - MonoBehaviour target：
  • フェード対象となるコンポーネント。 CanvasGroupがアタッチされていない場合は、自動的に追加して使用します。
  •  
  • - CanvasGroup target：
  • フェード対象となる CanvasGroup コンポーネント。
  •  
  • - float forwardValue：
  • アニメーションする際のforward 到達アルファ値（0〜1）。
  • 正方向（forward）再生時：- 現在の alpha → forwardValue に向かってフェードします。
  • 逆再生時：forwardValue → 現在の alpha に向かってフェードします。
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts を設定するかどうか。
  •  
  • - float duration：
  • アニメーションにかける時間（秒）。
  •  
  • - AnimationCurve curve：
  • アニメーションの進行に使用するカスタムカーブ。
  • カーブの時間軸がそのままアニメーション時間になるため、duration は無効化されます

・パラメータ
  • - Light target：
  • アニメーション対象となる UnityEngine.Light コンポーネント。
  •  
  • - Color color：
  • Light の color をアニメーションする際のforward 到達値。
  • 正方向（forward）再生時：現在の target.color → color に向かって変化します。
  • 逆再生時：color → 現在の target.color に向かって変化します。
  •  
  • - float intensity：
  • Light の intensity（明るさ）の forward 到達値。
  • 正方向（forward）再生時：現在値 → intensity に向かって変化します。
  • 逆再生：intensity → 現在値 に向かって変化します。
  •  
  • - float range：
  • Light の range（照射範囲）の forward 到達値。
  • 正方向（forward）再生時：現在値 → range に向かって変化します。
  • 逆再生：range → 現在値 に向かって変化します。
  •  
  • - float duration：
  • アニメーションにかける時間（秒）。
  •  
  • - AnimationCurve curve：

  • 正方向（forward）再生時：0 → rotate に向かって回転します。
  • 逆再生時：rotate → 0 に向かって回転します。
  •  
  • - float duration：
  • アニメーションにかける時間（秒）。
  •  
  • - AnimationCurve curve：
  • アニメーションの進行に使用するカスタムカーブ。
  • カーブの時間軸がそのままアニメーション時間になるため、duration は無効化されます。

▶ Path Settings

複数のポイントで構成されたカーブ（パス）に沿って対象オブジェクトを移動させるアニメーション機能です。

SetClosed(bool closed);

  • 曲線の開始点と終端を接続するかどうかを設定します。
・パラメータ
  • - bool closed：
  • true：曲線開始点と曲線終端を接続し、ループ状の閉じた曲線として扱います。
  • false：曲線を接続せず、開いた曲線として扱います。

SetLookMode(PathLookMode lookmode);

  • 移動中のオブジェクトがどの方向を向くかを設定します。
・パラメータ
  • - PathLookMode lookmode：
  • None：向きを変更しません。オブジェクトの現在の回転を維持します。
  • Forward：パスの進行方向（接線方向）を向きます。一般的な「パスに沿って進む」動作。
  • Right：パスの進行方向に対して 右方向（+X 軸側） を向きます。横向き移動などに使用。
  • Left：パスの進行方向に対して 左方向（–X 軸側） を向きます。Right の反対方向。

SetPoints(List vectors);

  • パスを構成する接続点（制御点）リストを設定します。

SetTarget(Transform target);

  • パスに沿って移動させる対象オブジェクト（Transform）を設定します。

SetUseLocalPosition(bool uselocal);

  • パス移動時に ローカル座標 を使用するかどうかを設定します。
・パラメータ
  • - bool uselocal：
  • true：ローカル座標を使用します。
  • false：ワールド座標を使用します。

SnapTargetToFirstPoint();

  • ターゲット位置を開始点にリセットします。

▶ CurveTween Settings

CurveTween の挙動を制御するための設定項目です。

SetDelay(float delay);

  • アニメーション開始までの待ち時間を設定します。

SetDuration(float duration);

  • アニメーションにかける時間（秒）を設定します。

SetEase(EaseType easeType);

  • EaseType に応じた 0〜1 の正規化カーブを設定します。（例：Linear、EaseInSine、EaseOutSine、EaseInOutSine など）

SetLoop(bool loop);

  • アニメーションをループさせるかどうかを設定します。
・パラメータ
  • - bool loop：
  • true：ループする。
  • false：ループしない。

SetLoopCount(int loopCount);

  • アニメーションを繰り返す回数を設定します。

SetLoopDelay(bool loopDelay);

  • ループ時に delay を使用するかどうかを設定します。
・パラメータ
  • - bool loopDelay：
  • true：ループ時に delayを使用する。
  • false：開始の時一回のみ使用する。

SetLoopType(LoopType loopType);

  • ループの種類を設定します。
・パラメータ
  • - LoopType loopType：
  • Resart：0 → 1 を繰り返します。
  • YoYo：0 → 1 → 0 を繰り返します。
  • Increment：既存の値に加算していきます。

SetScaledTime(bool scaledtime);

  • Time.timeScaleに依存するかどうかを設定します。デフォルトでは、依存します。
・パラメータ
  • - bool scaledtime：
  • true：Time.timeScaleに依存します。
  • false：依存しない。

SetYoYoDelay(float yoYoDelay);

  • LoopType.YoYo時に使います。0 → 1 に到達した後、この遅延を挟んでから 1 → 0 を実行します。

SetValue(object value);

  • アニメーション開始前に、ターゲットまたは forwardValue をリセットします。
  • CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float など

▶ Play / Stop

アニメーションの開始・停止を制御します。

void Play();

void Play(bool reversePlay);

  • アニメーションを再生します。
・パラメータ
  • - bool reversePlay：
  • true：逆再生します。
  • false：通常再生します。

void PlayOnce();

  • アニメーションを 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void PlayReverseOnce();

  • アニメーションを逆方向に 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void Stop();

  • 再生中または逆再生中のアニメーションを停止します。

void StopAndReset();

  • 再生中または逆再生中のアニメーションを停止し、初期状態にリセットします。

▶ Event Callbacks

アニメーションの開始・進行・完了時に呼ばれるイベントを登録します。

void AddOnStartListener(UnityAction call);

  • アニメーション開始時に呼ばれるイベントを登録します。

void AddOnYoYoListener(UnityAction call);

  • YoYo アニメーションで 0 → 1 に到達したタイミングで実行されるイベントを登録します。

void AddOnCompleteListener(UnityAction call);

  • アニメーションが終了したときに呼ばれるイベントを登録します。 ただし、ループ設定が有効な場合は実行しません。

▶ GetAnimationCurve

指定した EaseType に基づいて、アニメーションカーブ（Keyframe 配列）を生成して返します。EaseType の補間特性（Linear、EaseInSine、EaseOutSine、EaseInOutSine など）に応じた0〜1 の正規化カーブを構築し、Tween の補間処理に利用できます。

Keyframe[] GetAnimationCurve(EaseType easeType);

・パラメータ
  • - EaseType easeType：
  • 生成するアニメーションカーブの種類を指定します。
