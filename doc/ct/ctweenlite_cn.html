CurveTween Lite 文档

功能列表

▶ Fade（淡入淡出)

对对象的透明度（Alpha）进行动画处理。

• 支持的组件
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 使用示例
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移动)

对 Transform 的位置进行动画处理。

• 使用示例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（缩放)

对 Transform 的缩放进行动画处理。

• 使用示例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（旋转)

对 Transform 的旋转进行动画处理。

• 使用示例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（颜色)

对颜色（Color）进行动画处理。

• 支持的组件
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 使用示例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

实现打字机风格的文字动画。

• 使用示例
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

对 Unity Light 组件的属性进行动画处理。

• 支持的属性
  • - color
  • - intensity
  • - range
• 使用示例
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ FillAmount

用于为 Image 组件的 fillAmount 值制作动画的功能。 可用于血条、冷却时间、圆形加载等 UI 表现。

• 目标对象
  • - Image（Filled 类型）
• 使用示例
  • target.DoFillAmount(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ IntInterpolate / FloatInterpolate

用于在 Text / TextMeshPro 中对数值进行插值动画的功能。 适用于数字增长、伤害数字、分数动画等效果。

• 目标对象
  • - Text / TextMeshPro
• 使用示例
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

API 参考文档

▶ DoCanvasFade

用于为 CanvasGroup 的 alpha 值播放动画的实用方法。

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• 参数
  • - GameObject target：
  • 要进行淡入淡出的 UnityEngine.GameObject。若未挂载 CanvasGroup，则会自动添加并使用。
  •  
  • - MonoBehaviour target：
  • 要进行淡入淡出的组件。如果未挂载 CanvasGroup，将自动添加并使用。
  •  
  • - CanvasGroup target：
  • 要进行淡入淡出的 CanvasGroup 组件。
  •  
  • - float forwardValue：
  • 正向动画时的目标 alpha 值（0〜1）。
  • 正向播放：当前 alpha → forwardValue。
  • 反向播放：forwardValue → 当前 alpha。
  •  
  • - bool blocksraycasts：
  • 是否设置 CanvasGroup.blocksRaycasts。
  •  
  • - float duration：
  • 动画持续时间（秒）。
  •  
  • - AnimationCurve curve：
  • 用于控制动画进度的自定义曲线。
  • 由于曲线的时间轴即为动画时长，因此 duration 将被忽略。

▶ CurveTween Settings

iTweenPlayer SetDelay(float delay);

  • 设置动画开始前的延迟时间。

iTweenPlayer SetDuration(float duration);

  • 设置动画持续时间（秒）。

iTweenPlayer SetEase(EaseType easeType);

  • 根据 EaseType 设置 0–1 的标准化缓动曲线。

iTweenPlayer SetLoop(bool loop);

  • 设置动画是否循环。

iTweenPlayer SetLoopCount(int loopCount);

  • 设置动画重复次数。

ITweenPlayerSetLoopDelay(bool loopDelay);

  • 设置循环时是否应用 delay。

iTweenPlayer SetLoopType(LoopType loopType);

  • 设置循环类型
• 参数
  • - LoopType loopType：
  • Resart：0 → 1 重复
  • YoYo：0 → 1 → 0 重复
  • Increment：在现有值基础上累加

iTweenPlayer SetScaledTime(bool scaledtime);

  • 设置是否依赖 Time.timeScale。

iTweenPlayer SetYoYoDelay(float yoYoDelay);

  • YoYo 模式下，0 → 1 到达后反向前的延迟。

iTweenPlayer SetValue(object value);

  • 在动画开始前重置目标或 forwardValue。
  • 支持：CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float 等

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • 播放动画。
• 参数
  • - bool reversePlay：
  • reversePlay = true：反向播放

void PlayOnce();

  • 播放一次并在结束后释放（循环模式除外）。

void PlayReverseOnce();

  • 反向播放一次并在结束后释放（循环模式除外）。

void Stop();

  • 停止当前动画。

void ForceEnd(bool invokeCallback);

  • ForceEnd 方法用于跳过正常的结束流程，立即终止处理。
• 参数
  • - bool invokeCallback：
  • true：强制结束后执行完成回调。
  • false：不执行完成回调。

void StopAndReset();

  • 停止动画并重置到初始状态。

▶ Event Callbacks

iTweenPlayer AddOnStartListener(UnityAction call);

  • 动画开始时调用。

iTweenPlayer AddOnYoYoListener(UnityAction call);

  • YoYo 动画到达 1.0 时调用。

iTweenPlayer AddOnCompleteListener(UnityAction call);

  • 动画完成时调用（非循环模式）。
