CurveTween Lite 문서

기능 목록

▶ Fade（페이드)

오브젝트의 투명도(Alpha)를 애니메이션합니다.

• 지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 사용 예시
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（이동)

Transform의 위치를 애니메이션합니다.

• 사용 예시
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（확대/축소)

Transform의 스케일을 애니메이션합니다.

• 사용 예시
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（회전)

Transform의 회전을 애니메이션합니다.

• 사용 예시
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（컬러)

Color 값을 애니메이션합니다.

• 지원 컴포넌트
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 사용 예시
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

타이핑 효과의 텍스트 애니메이션을 제공합니다.

• 사용 예시
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Unity Light 컴포넌트의 다양한 속성을 애니메이션합니다.

• 지원 속성
  • - color
  • - intensity
  • - range
• 사용 예시
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ FillAmount

Image 컴포넌트의 fillAmount 값을 애니메이션하는 기능입니다. 게이지, 쿨다운, 원형 로딩 등 UI 표현에 사용할 수 있습니다.

• 대상
  • - Image (Filled 타입)
• 사용 예시
  • target.DoFillAmount(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ IntInterpolate / FloatInterpolate

Text / TextMeshPro의 숫자 값을 보간하여 애니메이션으로 표시하는 기능입니다. 카운트업, 데미지 숫자, 점수 연출 등에 적합합니다.

• 대상
  • - Text / TextMeshPro
• 사용 예시
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

API 참고 문서

▶ DoCanvasFade

CanvasGroup의 alpha 값을 애니메이션하기 위한 유틸리티 메서드입니다.

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• 파라미터
  • - GameObject target：
  • 페이드 대상이 되는 UnityEngine.GameObject입니다. CanvasGroup이 부착되어 있지 않다면 자동으로 추가하여 사용합니다.
  •  
  • - MonoBehaviour target：
  • 페이드 대상이 되는 컴포넌트입니다. CanvasGroup이 없을 경우 자동으로 추가하여 사용합니다.
  •  
  • - CanvasGroup target：
  • 페이드 대상이 되는 CanvasGroup 컴포넌트입니다.
  •  
  • - float forwardValue：
  • 애니메이션 시 forward 방향의 목표 알파 값(0〜1)입니다.
  • 정방향 재생: 현재 alpha → forwardValue.
  • 역방향 재생: forwardValue → 현재 alpha.
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts 값을 설정할지 여부입니다.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초)입니다.
  •  
  • - AnimationCurve curve：
  • 애니메이션 진행에 사용되는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간이 되므로 duration은 무시됩니다.

  • 애니메이션 진행을 제어하는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간이 되므로 duration은 무시됩니다.

ITweenPlayer DoScaleZ<T>(this T target, float z, AnimationCurve curve) where T : Component;

ITweenPlayer DoScale<T>(this T target, Vector3 forwardValue, float duration = 1, bool relative = false) where T : Component;

ITweenPlayer DoScale<T>(this T target, Vector3 forwardValue, AnimationCurve curve, bool relative = false) where T : Component;

• 파라미터
  • - GameObject target：
  • 스케일 애니메이션 대상이 되는 UnityEngine.GameObject입니다. Transform을 가진 오브젝트라면 사용할 수 있습니다.
  •  
  • - T target：
  • 스케일 애니메이션 대상이 되는 컴포넌트입니다. Transform을 가진 컴포넌트라면 사용할 수 있습니다.
  •  
  • - Vector3 forwardValue：
  • 정방향 재생 시 도달할 스케일 값입니다.
  • 정방향 재생: 현재 값 → forwardValue.
  • 역방향 재생: forwardValue → 현재 값.
  •  
  • - float x / y / z：
  • (x/y/z) 축 스케일의 forward 도달 값입니다.
  • 정방향 재생: 현재 값 → (x/y/z).
  • 역방향 재생: (x/y/z) → 현재 값.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초)입니다.
  •  
  • - AnimationCurve curve：
  • 애니메이션 진행을 제어하는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간이 되므로 duration은 무시됩니다.

ITweenPlayer DoReveal(this Text target, string text = null, float duration = 1);

• 파라미터
  • - Text target：

  •

  • 타자기 애니메이션으로 표시할 텍스트입니다.
  •  
  • - float duration：
  • 애니메이션에 걸리는 시간(초)입니다.
  •  
  • - AnimationCurve curve：
  • 애니메이션 진행을 제어하는 커스텀 커브입니다.
  • 커브의 시간축이 그대로 애니메이션 시간이 되므로 duration은 무시됩니다.

▶ CurveTween Settings

iTweenPlayer SetDelay(float delay);

  • 애니메이션 시작 전 지연 시간을 설정합니다.

iTweenPlayer SetDuration(float duration);

  • 애니메이션 지속 시간을 설정합니다.

iTweenPlayer SetEase(EaseType easeType);

  • EaseType에 따른 0–1 정규화 커브를 설정합니다.

iTweenPlayer SetLoop(bool loop);

  • 애니메이션 반복 여부를 설정합니다.

iTweenPlayer SetLoopCount(int loopCount);

  • 반복 횟수를 설정합니다.

iTweenPlayer SetLoopDelay(bool loopDelay);

  • 반복 시 delay를 적용할지 설정합니다.

iTweenPlayer SetLoopType(LoopType loopType);

  • 반복 방식 설정
• 파라미터
  • - LoopType loopType：
  • Resart：0 → 1 반복
  • YoYo：0 → 1 → 0 반복
  • Increment：기존 값에 누적

iTweenPlayer SetScaledTime(bool scaledtime);

  • Time.timeScale에 의존할지 설정합니다.

iTweenPlayer SetYoYoDelay(float yoYoDelay);

  • YoYo 모드에서 0 → 1 도달 후 역방향 재생 전 지연 시간.

iTweenPlayer SetValue(object value);

  • 애니메이션 시작 전에 target 또는 forwardValue를 초기화합니다.
  • 지원 타입: CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float 등

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • 애니메이션을 재생합니다.
• 파라미터
  • - bool reversePlay：
  • reversePlay = true: 역방향 재생

void PlayOnce();

  • 한 번만 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void PlayReverseOnce();

  • 역방향으로 한 번 재생하고 종료 후 해제합니다. (루프 설정 시 해제하지 않음)

void Stop();

  • 재생 중인 애니메이션을 중지합니다.

void ForceEnd(bool invokeCallback);

  • ForceEnd 메서드는 정상적인 종료 흐름을 무시하고 즉시 처리를 종료합니다.
• 파라미터
  • - bool invokeCallback：
  • true：강제 종료 후 완료 콜백을 실행함.
  • false：완료 콜백을 실행하지 않음.

void StopAndReset();

  • 애니메이션을 중지하고 초기 상태로 되돌립니다.

▶ Event Callbacks

iTweenPlayer AddOnStartListener(UnityAction call);

  • 애니메이션 시작 시 호출됩니다.

iTweenPlayer AddOnYoYoListener(UnityAction call);

iTweenPlayer AddOnCompleteListener(UnityAction call);

  • 애니메이션 완료 시 호출됩니다. (루프 중에는 호출되지 않음)
