CurveTween Lite ドキュメント

機能一覧 (Features)

▶ Fade（フェード)

オブジェクトの透明度（Alpha）をアニメーションします。

• 対象
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 使用例
  • target.DoFade(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移動)

Transform の位置をアニメーションします。

• 使用例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（拡大縮小)

Transform のスケールをアニメーションします。

• 使用例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（回転)

Transform の回転をアニメーションします。

• 使用例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（カラー)

色（Color）をアニメーションします。

• 対象
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 使用例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

テキストのタイピング風アニメーションします。

• 使用例
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Unity Light コンポーネントの各種プロパティをアニメーションします。

• 対象

  • - intensity
  • - range
• 使用例

▶ FillAmount

Image コンポーネントの fillAmount をアニメーションさせる機能です。 ゲージ • クールダウン • 円形ロードなど、UI 表現に利用できます。

• 対象
  • - Image（Filled タイプ）
• 使用例
  • target.DoFillAmount(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ IntInterpolate / FloatInterpolate

Text / TextMeshPro の数値を補間しながらアニメーション表示する機能です。 カウントアップ、ダメージ数値、スコア演出などに最適です。

• 対象
  • - Text/TextMeshPro
• 使用例
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

APIリファレンス

▶ DoCanvasFade

CanvasGroupの alpha をアニメーションさせるためのユーティリティメソッドです。

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• パラメータ
  • - GameObject target：
  • フェード対象となる UnityEngine.GameObject。CanvasGroupがアタッチされていない場合は、自動的に追加して使用します。
  •  
  • - MonoBehaviour target：
  • フェード対象となるコンポーネント。 CanvasGroupがアタッチされていない場合は、自動的に追加して使用します。
  •  
  • - CanvasGroup target：
  • フェード対象となる CanvasGroup コンポーネント。
  •  
  • - float forwardValue：
  • アニメーションする際のforward 到達アルファ値（0〜1）。
  • 正方向（forward）再生時：- 現在の alpha → forwardValue に向かってフェードします。
  • 逆再生時：forwardValue → 現在の alpha に向かってフェードします。
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts を設定するかどうか。
  •  
  • - float duration：
  • アニメーションにかける時間（秒）。
  •  
  • - AnimationCurve curve：
  • アニメーションの進行に使用するカスタムカーブ。
  • カーブの時間軸がそのままアニメーション時間になるため、duration は無効化されます

▶ CurveTween Settings

CurveTween の挙動を制御するための設定項目です。

iTweenPlayer SetDelay(float delay);

  • アニメーション開始までの待ち時間を設定します。

iTweenPlayer SetDuration(float duration);

  • アニメーションにかける時間（秒）を設定します。

iTweenPlayer SetEase(EaseType easeType);

  • EaseType に応じた 0〜1 の正規化カーブを設定します。（例：Linear、EaseInSine、EaseOutSine、EaseInOutSine など）

iTweenPlayer SetLoop(bool loop);

  • アニメーションをループさせるかどうかを設定します。
• パラメータ
  • - bool loop：
  • true：ループする。
  • false：ループしない。

iTweenPlayer SetLoopCount(int loopCount);

  • アニメーションを繰り返す回数を設定します。

iTweenPlayer SetLoopDelay(bool loopDelay);

  • ループ時に delay を使用するかどうかを設定します。
• パラメータ
  • - bool loopDelay：
  • true：ループ時に delayを使用する。
  • false：開始の時一回のみ使用する。

iTweenPlayer SetLoopType(LoopType loopType);

  • ループの種類を設定します。
• パラメータ
  • - LoopType loopType：
  • Resart：0 → 1 を繰り返します。
  • YoYo：0 → 1 → 0 を繰り返します。
  • Increment：既存の値に加算していきます。

iTweenPlayer SetScaledTime(bool scaledtime);

  • Time.timeScaleに依存するかどうかを設定します。デフォルトでは、依存します。
• パラメータ
  • - bool scaledtime：
  • true：Time.timeScaleに依存します。
  • false：依存しない。

iTweenPlayer SetYoYoDelay(float yoYoDelay);

  • LoopType.YoYo時に使います。0 → 1 に到達した後、この遅延を挟んでから 1 → 0 を実行します。

iTweenPlayer SetValue(object value);

  • アニメーション開始前に、ターゲットまたは forwardValue をリセットします。
  • CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float など

▶ Play / Stop

アニメーションの開始 • 停止を制御します。

void Play();

void Play(bool reversePlay);

  • アニメーションを再生します。
• パラメータ
  • - bool reversePlay：
  • true：逆再生します。
  • false：通常再生します。

void PlayOnce();

  • アニメーションを 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void PlayReverseOnce();

  • アニメーションを逆方向に 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void Stop();

  • 再生中または逆再生中のアニメーションを停止します。

void ForceEnd(bool invokeCallback);

  • ForceEnd は、通常の終了フローを無視して即座に処理を終わらせるためのメソッド。
• パラメータ
  • - bool invokeCallback：
  • true：強制終了後に 完了コールバックを実行する。
  • false：完了コールバックを実行しない。

void StopAndReset();

  • 再生中または逆再生中のアニメーションを停止し、初期状態にリセットします。

▶ Event Callbacks

アニメーションの開始 • 進行 • 完了時に呼ばれるイベントを登録します。

iTweenPlayer AddOnStartListener(UnityAction call);

  • アニメーション開始時に呼ばれるイベントを登録します。

iTweenPlayer AddOnYoYoListener(UnityAction call);

  • YoYo アニメーションで 0 → 1 に到達したタイミングで実行されるイベントを登録します。

iTweenPlayer AddOnCompleteListener(UnityAction call);

  • アニメーションが終了したときに呼ばれるイベントを登録します。 ただし、ループ設定が有効な場合は実行しません。
