CurveTween ドキュメント

機能一覧 (Features)

▶ Fade（フェード)

オブジェクトの透明度（Alpha）をアニメーションします。

• 対象
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 使用例
  • target.DoFade(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移動)

Transform の位置をアニメーションします。

• 使用例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（拡大縮小)

Transform のスケールをアニメーションします。

• 使用例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（回転)

Transform の回転をアニメーションします。

• 使用例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（カラー)

色（Color）をアニメーションします。

• 対象
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 使用例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

テキストのタイピング風アニメーションします。

• 使用例
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ RichText (TextMeshPro)

リッチテキストに対応し、タイピング風アニメーション、回転アニメーション、フォントサイズの拡大縮小アニメーションをサポートします。(ただし GC 負荷が高い 点に注意が必要です)

• 使用例
  • target.DoRichTextReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 使用例
  • target.DoRichTextTween(duration: 1.5f).SetText(text).SetReveal(false)
  • .SetFontSizeTween(true).SetValue(fontsize)
  • .SetRotateTween(true).SetValue(rot)
  • .Play();

▶ Light

Unity Light コンポーネントの各種プロパティをアニメーションします。

• 対象

  • - range
• 使用例

  • .SetEase(EaseType.EaseOutCubic)

▶ FillAmount

Image コンポーネントの fillAmount をアニメーションさせる機能です。 ゲージ • クールダウン • 円形ロードなど、UI 表現に利用できます。

• 対象

• 使用例

▶ IntInterpolate / FloatInterpolate

Text / TextMeshPro の数値を補間しながらアニメーション表示する機能です。 カウントアップ、ダメージ数値、スコア演出などに最適です。

• 対象
  • - Text/TextMeshPro
• 使用例
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TMPMeshExplodeInAnimation

TextMeshPro の頂点データを直接操作し、文字を個別に爆発させるアニメーションです。 速度 • 方向 • 拡散度 • ランダム性などを細かく制御でき、派手な演出に向いています。

• 対象
  • - TextMeshPro
• 使用例
  • path.DoMeshExplodeIn()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 使用例
  • path.DoMeshExplodeIn()
  • .SetExplosionPower(power)
  • .SetUseFadeOut(true).SetFadeDelay(delay)
  • .SetUseRotate(true).SetValue(min, max)
  • .SetUseFloatiness(true).SetValue(min, max)
  • .Play();

▶ TMPMeshRevealAnimation

TextMeshPro の頂点を直接操作し、以下の複合的な文字演出を実現するアニメーションです。 Fade（透明度）、Character Scale（文字スケール）、Rotate（回転）、Move（移動）、Wave（波形変形）、Bounce（バウンス変形）、 タイプライター風の演出から、動きのある複雑な文字アニメーションまで幅広く対応します。

• 対象
  • - TextMeshPro
• 使用例
  • path.DoMeshReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 使用例
  • path.DoMeshReveal()
  • .SetFadeTween(true).SetValue(alpha)
  • .SetScaleTween(true).SetValue(scale)
  • .SetPosTween(true).SetValue(pos)
  • .SetWave(WaveType).SetFactor(float)
  • .SetRotTween(true).SetValue(rot)
  • .Play();

▶ PathCurveAnimation

PathCurveAnimation は、複数のポイントで構成されたカーブ（パス）に沿って対象オブジェクトを移動させるアニメーション機能です。

• 使用例
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

APIリファレンス

▶ DoCanvasFade

CanvasGroupの alpha をアニメーションさせるためのユーティリティメソッドです。

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• パラメータ
  • - GameObject target：
  • フェード対象となる UnityEngine.GameObject。CanvasGroupがアタッチされていない場合は、自動的に追加して使用します。
  •  
  • - MonoBehaviour target：
  • フェード対象となるコンポーネント。 CanvasGroupがアタッチされていない場合は、自動的に追加して使用します。
  •  
  • - CanvasGroup target：
  • フェード対象となる CanvasGroup コンポーネント。
  •  
  • - float forwardValue：
  • アニメーションする際のforward 到達アルファ値（0〜1）。
  • 正方向（forward）再生時：- 現在の alpha → forwardValue に向かってフェードします。
  • 逆再生時：forwardValue → 現在の alpha に向かってフェードします。
  •  
  • - bool blocksraycasts：
  • CanvasGroup.blocksRaycasts を設定するかどうか。
  •  
  • - float duration：
  • アニメーションにかける時間（秒）。
  •  
  • - AnimationCurve curve：
  • アニメーションの進行に使用するカスタムカーブ。
  • カーブの時間軸がそのままアニメーション時間になるため、duration は無効化されます

  •  
  • - float range：
  • Light の range（照射範囲）の forward 到達値。
  • 正方向（forward）再生時：現在値 → range。
  • 逆再生：range → 現在値。

▶ Path Settings

複数のポイントで構成されたカーブ（パス）に沿って対象オブジェクトを移動させるアニメーション機能です。

IPathPlayer SetClosed(bool closed);

  • 曲線の開始点と終端を接続するかどうかを設定します。
• パラメータ
  • - bool closed：
  • true：曲線開始点と曲線終端を接続し、ループ状の閉じた曲線として扱います。
  • false：曲線を接続せず、開いた曲線として扱います。

IPathPlayer SetLookMode(PathLookMode lookmode);

  • 移動中のオブジェクトがどの方向を向くかを設定します。
• パラメータ
  • - PathLookMode lookmode：
  • None：向きを変更しません。オブジェクトの現在の回転を維持します。
  • Forward：パスの進行方向（接線方向）を向きます。一般的な「パスに沿って進む」動作。
  • Right：パスの進行方向に対して 右方向（+X 軸側） を向きます。横向き移動などに使用。
  • Left：パスの進行方向に対して 左方向（–X 軸側） を向きます。Right の反対方向。

IPathPlayer SetPoints(List vectors);

  • パスを構成する接続点（制御点）リストを設定します。

IPathPlayer SetTarget(Transform target);

  • パスに沿って移動させる対象オブジェクト（Transform）を設定します。

IPathPlayer SetUseLocalPosition(bool uselocal);

  • パス移動時に ローカル座標 を使用するかどうかを設定します。
• パラメータ
  • - bool uselocal：
  • true：ローカル座標を使用します。
  • false：ワールド座標を使用します。

IPathPlayer SnapTargetToFirstPoint();

  • ターゲット位置を開始点にリセットします。

▶ CurveTween Settings

CurveTween の挙動を制御するための設定項目です。

iTweenPlayer SetDelay(float delay);

  • アニメーション開始までの待ち時間を設定します。

iTweenPlayer SetDuration(float duration);

  • EaseType に応じた 0〜1 の正規化カーブを設定します。（例：Linear、EaseInSine、EaseOutSine、EaseInOutSine など）

iTweenPlayer SetLoop(bool loop);

  • アニメーションをループさせるかどうかを設定します。
• パラメータ
  • - bool loop：
  • true：ループする。
  • false：ループしない。

iTweenPlayer SetLoopCount(int loopCount);

  • アニメーションを繰り返す回数を設定します。

iTweenPlayer SetLoopDelay(bool loopDelay);

  • ループ時に delay を使用するかどうかを設定します。
• パラメータ
  • - bool loopDelay：
  • true：ループ時に delayを使用する。

  • false：依存しない。

iTweenPlayer SetValue(object value);

  • CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float など

▶ Play / Stop

アニメーションの開始 • 停止を制御します。

void Play();

void Play(bool reversePlay);

  • アニメーションを再生します。
• パラメータ
  • - bool reversePlay：
  • true：逆再生します。
  • false：通常再生します。

void PlayOnce();

  • アニメーションを 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void PlayReverseOnce();

  • アニメーションを逆方向に 1 回だけ再生し、終了後に解放します。 ただし、ループ設定が有効な場合は解放しません。

void Stop();

  • 再生中または逆再生中のアニメーションを停止します。

void ForceEnd(bool invokeCallback);

  • ForceEnd は、通常の終了フローを無視して即座に処理を終わらせるためのメソッド。
• パラメータ
  • - bool invokeCallback：
  • true：強制終了後に 完了コールバックを実行する。
  • false：完了コールバックを実行しない。

void StopAndReset();

  • 再生中または逆再生中のアニメーションを停止し、初期状態にリセットします。
