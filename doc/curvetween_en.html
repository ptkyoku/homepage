CurveTween

Features

▶ Fade

Animates the object's transparency (Alpha).

・・Supported Components
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
・Example
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move

Animates the position of a Transform.

・Example
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale

Animates the scale of a Transform.

・Example
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate

Animates the rotation of a Transform.

・Example
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color

Animates color values.

・Supported Components
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
・Example
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

Creates a typewriter-style text animation.

・Example
  • target.DoTextTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TextPro (TextMeshPro)

Supports rich text, typewriter animation, rotation animation, and font-size scaling animation.

・Example
  • target.DoTextProTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

Animates various properties of a Unity Light component.

・Supported Properties
  • - color
  • - intensity
  • - range
・Example
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ PathCurveAnimation

Moves a target object along a curve (path) composed of multiple points.

・Example
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

▶ DoCanvasFade

Utility method for animating the alpha value of a CanvasGroup.

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, float duration = 1);

・Parameters
  • - MonoBehaviour target：
  • The component whose CanvasGroup will be faded. If the object does not have a CanvasGroup, one is automatically added.
  •  
  • - CanvasGroup target：
  • The CanvasGroup component to animate.
  •  
  • - float forwardValue：
  • The target alpha value (0–1) when playing forward.
  • Forward: current alpha → forwardValue
  • Reverse: forwardValue → current alpha
  •  
  • - bool blocksraycasts：
  • Whether to set CanvasGroup.blocksRaycasts.
  •  
  • - float duration：
  • Duration of the animation in seconds.
  •  
  • - AnimationCurve curve：
  • Custom animation curve.
  • When this is set, its time axis becomes the animation duration, and duration is ignored.

▶ Path Settings

Animation system for moving objects along a multi-point curve (path).

SetClosed(bool closed);

  • Whether to connect the start and end points.
・Parameters
  • - bool closed：
  • true: closed loop
  • false: open curve

SetLookMode(PathLookMode lookmode);

  • Controls the facing direction of the moving object.
・Parameters
  • - PathLookMode lookmode：
  • None: keep current rotation
  • Forward: face tangent direction
  • Right: face +X relative to path direction
  • Left: face –X relative to path direction

SetPoints(List vectors);

  • Sets the control points of the path.

SetTarget(Transform target);

  • Sets the object to move along the path.

SetUseLocalPosition(bool uselocal);

  • Whether to use local coordinates.
・Parameters
  • - bool uselocal：
  • true: use local position
  • false: use world position

SnapTargetToFirstPoint();

  • Moves the target to the first point

▶ CurveTween Settings

SetDelay(float delay);

  • Delay before animation starts.

SetDuration(float duration);

  • Animation duration in seconds.

SetEase(EaseType easeType);

  • Sets normalized 0–1 easing curve.

SetLoop(bool loop);

  • Whether to loop the animation.

SetLoopCount(int loopCount);

  • Number of loops.

SetLoopDelay(bool loopDelay);

  • Whether to apply delay on loops.

SetLoopType(LoopType loopType);

  • Loop behavior
・Parameters
  • - LoopType loopType：
  • Resart
  • YoYo
  • Increment

SetScaledTime(bool scaledtime);

  • Whether to use Time.timeScale.

SetYoYoDelay(float yoYoDelay);

  • Delay before reverse motion in YoYo mode.

SetValue(object value);

  • Resets target or forwardValue before animation.
  • CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float etc.

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • Starts animation.
・Parameters
  • - bool reversePlay：
  • reversePlay = true → play backward

void PlayOnce();

  • Plays once and releases unless looping.

void PlayReverseOnce();

  • Reverse once and release unless looping.

void Stop();

  • Stops animation.

void StopAndReset();

  • Stops and resets to initial state.
