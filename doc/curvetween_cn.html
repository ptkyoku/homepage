CurveTween 文档

功能列表

▶ Fade（淡入淡出)

对对象的透明度（Alpha）进行动画处理。

・支持的组件
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
・示例
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移动)

对 Transform 的位置进行动画处理。

・示例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（缩放)

对 Transform 的缩放进行动画处理。

・示例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（旋转)

对 Transform 的旋转进行动画处理。

・示例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（颜色)

对颜色（Color）进行动画处理。

・支持的组件
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
・示例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

实现打字机风格的文字动画。

・示例
  • target.DoTextTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TextPro (TextMeshPro)

支持富文本、打字机动画、旋转动画、字体大小缩放动画。

・示例
  • target.DoTextProTypewriter()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

对 Unity Light 组件的属性进行动画处理。

・支持的属性
  • - color
  • - intensity
  • - range
・示例
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ PathCurveAnimation

沿由多个点组成的曲线（路径）移动目标对象。

・示例
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

▶ DoCanvasFade

用于为 CanvasGroup 的 alpha 值创建淡入淡出动画的实用方法。

DoCanvasFade(this MonoBehaviour target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this MonoBehaviour target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, AnimationCurve curve);

DoCanvasFade(this CanvasGroup target, float forwardValue, float duration = 1);

DoCanvasFade(this CanvasGroup target, float forwardValue, bool blocksraycasts, float duration = 1);

・参数
  • - MonoBehaviour target：
  • 需要进行淡入淡出的组件。 如果对象没有 CanvasGroup，将自动添加一个并使用。
  •  
  • - CanvasGroup target：
  • 要进行淡入淡出的 CanvasGroup 组件。
  •  
  • - float forwardValue：
  • 正向播放时的目标 alpha 值（0–1）。
  • 正向：当前 alpha → forwardValue
  • 反向：forwardValue → 当前 alpha
  •  
  • - bool blocksraycasts：
  • 是否设置 CanvasGroup.blocksRaycasts。
  •  
  • - float duration：
  • 动画持续时间（秒）。
  •  
  • - AnimationCurve curve：
  • 自定义动画曲线。
  • 当设置此参数时，曲线的时间轴将直接作为动画时长，duration 将被忽略。

▶ Path Settings

用于沿由多个点组成的曲线（路径）移动对象的动画功能。

SetClosed(bool closed);

  • 设置是否将路径的起点和终点连接。
・参数
  • - bool closed：
  • true：闭合曲线
  • false：开放曲线

SetLookMode(PathLookMode lookmode);

  • 设置对象在移动过程中的朝向。
・参数
  • - PathLookMode lookmode：
  • None：保持当前旋转
  • Forward：面向路径切线方向
  • Right：面向路径方向的右侧（+X）
  • Left：面向路径方向的左侧（–X）

SetPoints(List vectors);

  • 设置路径的控制点列表。

SetTarget(Transform target);

  • 设置沿路径移动的目标对象。

SetUseLocalPosition(bool uselocal);

  • 设置是否使用本地坐标。
・参数
  • - bool uselocal：
  • true：使用本地坐标
  • false：使用世界坐标

SnapTargetToFirstPoint();

  • 将目标对象重置到路径的第一个点。

▶ CurveTween Settings

SetDelay(float delay);

  • 设置动画开始前的延迟时间。

SetDuration(float duration);

  • 设置动画持续时间（秒）。

SetEase(EaseType easeType);

  • 根据 EaseType 设置 0–1 的标准化缓动曲线。

SetLoop(bool loop);

  • 设置动画是否循环。

SetLoopCount(int loopCount);

  • 设置动画重复次数。

SetLoopDelay(bool loopDelay);

  • 设置循环时是否应用 delay。

SetLoopType(LoopType loopType);

  • 设置循环类型
・参数
  • - LoopType loopType：
  • Resart：0 → 1 重复
  • YoYo：0 → 1 → 0 重复
  • Increment：在现有值基础上累加

SetScaledTime(bool scaledtime);

  • 设置是否依赖 Time.timeScale。

SetYoYoDelay(float yoYoDelay);

  • YoYo 模式下，0 → 1 到达后反向前的延迟。

SetValue(object value);

  • 在动画开始前重置目标或 forwardValue。
  • 支持：CanvasGroup / Graphic / Material / Transform / Text / TMP_Text / Vector3 / String / float 等

▶ Play / Stop

void Play();

void Play(bool reversePlay);

  • 播放动画。
・参数
  • - bool reversePlay：
  • reversePlay = true：反向播放

  • 播放一次并在结束后释放（循环模式除外）。

void PlayReverseOnce();

void Stop();

  • 停止当前动画。

void StopAndReset();

  • 停止动画并重置到初始状态。
