CurveTween 文档

功能列表

▶ Fade（淡入淡出)

对对象的透明度（Alpha）进行动画处理。

• 支持的组件
  • - SpriteRenderer
  • - Image
  • - CanvasGroup
  • - Text/TextMeshPro
  • - Material（Color の Alpha）
• 使用示例
  • target.DoFade(1f)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Move（移动)

对 Transform 的位置进行动画处理。

• 使用示例
  • target.DoMove(position)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Scale（缩放)

对 Transform 的缩放进行动画处理。

• 使用示例
  • target.DoScale(scale)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Rotate（旋转)

对 Transform 的旋转进行动画处理。

• 使用示例
  • target.DoRotation(rotate)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Color（颜色)

对颜色（Color）进行动画处理。

• 支持的组件
  • - SpriteRenderer
  • - Image
  • - Text/TextMeshPro
  • - Material（Color）
• 使用示例
  • target.DoColor(color)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Text（UI Text/TextMeshPro）

实现打字机风格的文字动画。

• 使用示例
  • target.DoReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ RichText (TextMeshPro)

支持富文本、打字效果动画、旋转动画以及字体大小缩放动画。(需要注意的是，它的 GC 开销较高，可能会影响性能。)

• 使用示例
  • target.DoRichTextReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ Light

对 Unity Light 组件的属性进行动画处理。

• 支持的属性
  • - color
  • - intensity
  • - range
• 使用示例
  • target.DoLight(color, intensity, range)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ FillAmount

用于为 Image 组件的 fillAmount 值制作动画的功能。 可用于血条、冷却时间、圆形加载等 UI 表现。

• 目标对象
  • - Image（Filled 类型）
• 使用示例
  • target.DoFillAmount(float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ IntInterpolate / FloatInterpolate

用于在 Text / TextMeshPro 中对数值进行插值动画的功能。 适用于数字增长、伤害数字、分数动画等效果。

• 目标对象
  • - Text / TextMeshPro
• 使用示例
  • target.DoInterpolate(int/float)
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();

▶ TMPMeshExplodeInAnimation

直接操作 TextMeshPro 顶点数据，使每个字符单独爆炸的动画。 可细致控制速度、方向、扩散度、随机性等，非常适合华丽的特效。

• 目标对象
  • - TextMeshPro
• 使用示例
  • path.DoMeshExplodeIn()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 使用示例
  • path.DoMeshExplodeIn()
  • .SetExplosionPower(power)
  • .SetUseFadeOut(true).SetFadeDelay(delay)
  • .SetUseRotate(true).SetValue(min, max)
  • .SetUseFloatiness(true).SetValue(min, max)
  • .Play();

▶ TMPMeshRevealAnimation

直接操作 TextMeshPro 顶点，实现以下复杂的文字动画效果： 透明度（Fade）、字符缩放（Scale）、旋转（Rotate）、移动（Move）、波形变形（Wave）、弹跳变形（Bounce）。 从打字机效果到动态复杂的文字动画都能实现。

• 目标对象
  • - TextMeshPro
• 使用示例
  • path.DoMeshReveal()
  • .SetEase(EaseType.EaseOutCubic)
  • .SetLoopType(LoopType.YoYo)
  • .Play();
• 使用示例
  • path.DoMeshReveal()
  • .SetFadeTween(true).SetValue(alpha)
  • .SetScaleTween(true).SetValue(scale)
  • .SetPosTween(true).SetValue(pos)
  • .SetWave(WaveType).SetFactor(float)
  • .SetRotTween(true).SetValue(rot)
  • .Play();

▶ PathCurveAnimation

沿由多个点组成的曲线（路径）移动目标对象。

• 使用示例
  • path.SetTarget(target)
  • .SnapTargetToFirstPoint()
  • .Play();

▶ DoCanvasFade

用于为 CanvasGroup 的 alpha 值播放动画的实用方法。

ITweenPlayer DoCanvasFade(this GameObject target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this GameObject target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this MonoBehaviour target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

ITweenPlayer DoCanvasFade(this CanvasGroup target, float forwardValue = 0, bool blocksraycasts = false, float duration = 1);

ITweenPlayer DoCanvasFade(this CanvasGroup target, AnimationCurve curve, float forwardValue = 0, bool blocksraycasts = false);

• 参数
  • - GameObject target：
  • 要进行淡入淡出的 UnityEngine.GameObject。若未挂载 CanvasGroup，则会自动添加并使用。
  •  
  • - MonoBehaviour target：
  • 要进行淡入淡出的组件。如果未挂载 CanvasGroup，将自动添加并使用。
  •  
  • - CanvasGroup target：
  • 要进行淡入淡出的 CanvasGroup 组件。
  •  
  • - float forwardValue：
  • 正向动画时的目标 alpha 值（0〜1）。
  • 正向播放：当前 alpha → forwardValue。
  • 反向播放：forwardValue → 当前 alpha。
  •  
  • - bool blocksraycasts：
  • 是否设置 CanvasGroup.blocksRaycasts。
  •  
  • - float duration：
  • 动画持续时间（秒）。
  •  
  • - AnimationCurve curve：
  • 用于控制动画进度的自定义曲线。
  • 由于曲线的时间轴即为动画时长，因此 duration 将被忽略。
